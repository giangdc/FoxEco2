# Log Bug — Mode UPDATE

> `/log-bug --update BUG-001 --status "Fixed"`

Đọc bug report → sửa status (hoặc severity/platform/defect/effect/round_found/round_closed/
rework_number/wont_fix_reason nếu user chỉ định) → đồng bộ bug-index.md → đồng bộ lại row tương ứng
trong Bug Data sheet (xem `references/sync-excel.md`).
Lifecycle: Open → In Progress → Fixed → Verified → Closed.
